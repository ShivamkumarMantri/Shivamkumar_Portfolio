# Shivamkumar Mantri — Portfolio

A responsive React + Vite portfolio inspired by the section structure and interaction style of the reference portfolio at https://www.shivam-portfolio.tech/ while using Shivamkumar Chandrakant Mantri's resume content.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Deploy on Vercel
Import the project into Vercel. Framework preset: Vite. Build command: `npm run build`. Output directory: `dist`.

## Included
- Home / hero with CTA buttons
- About
- Projects
- Skills
- Experience
- Education & certifications
- Contact
- Responsive mobile navigation
- GitHub / LinkedIn / email / phone buttons
- Downloadable resume in `public/Shivamkumar_Resume.pdf`
